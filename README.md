# Світло · Ірпінь · черга 6.2

Telegram-бот, який стежить за графіком стабілізаційних відключень ДТЕК (Київська область) для черги **6.2** і:

- надсилає **графік на завтра**, щойно його опублікують (і оновлення, якщо графік змінять);
- повідомляє, якщо змінився графік **на сьогодні**;
- нагадує **за 30 хв до відключення** і **за 30 хв до включення**.

Команди: `/start` (підписатися), `/today`, `/tomorrow`, `/now`, `/stop` — бот відповідає одразу.

**Групи:** додайте бота в групу — він сам підпишеться й надсилатиме туди те саме. `/stop` у групі вимикає сповіщення, видалення бота з групи — теж.

## Як це працює

- Дані: [Baskerville42/outage-data-ua](https://github.com/Baskerville42/outage-data-ua) (`data/kyiv-region.json`, поле `fact`) — це парсинг сайту ДТЕК КРЕМ.
- Запуск: GitHub Actions (`.github/workflows/bot.yml`). Кожен запуск працює ~55 хв у режимі long polling (`bot.py --loop 55`) і на старті ставить у чергу наступний, тож бот онлайн безперервно (пауза на перемиканні ~30–60 с). Cron раз на 30 хв — страховка.
- Графік перечитується раз на 5 хв; нагадування надсилаються точно за 30 хв.
- Стан (підписники, що вже надіслано) зберігається в кеші GitHub Actions, не в репозиторії.
- Залежностей немає — лише Python 3.9+.

## Налаштування

1. Створіть бота в [@BotFather](https://t.me/BotFather) і скопіюйте токен.
2. Додайте токен у секрети репозиторію:
   ```bash
   gh secret set TELEGRAM_BOT_TOKEN
   ```
3. Запустіть workflow один раз (`gh workflow run bot.yml`) і напишіть боту `/start`.

Інша черга чи регіон: змінні оточення `OUTAGE_GROUP` (напр. `GPV3.1`), `OUTAGE_PLACE`, `OUTAGE_DATA_URL`.

## Локальна перевірка

```bash
python3 bot.py --preview                                  # графік і найближчі події
STATE_FILE=/tmp/s.json python3 bot.py --dry-run --now 2026-11-27T05:35   # імітація часу
```
